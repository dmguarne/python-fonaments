# Agenda Persistent, Agenda Persistent v2 (Python)

Petit gestor de contactes fet en Python amb persistència de dades mitjançant JSON.

## Què fa?

- Afegir contactes
- Mostrar agenda
- Cercar per nom
- Afegir contactes
- Eliminar contactes
- Guardar automàticament en fitxer JSON
- Gestió d'errors amb try/except

## Tecnologies utilitzades

- Python 3
- JSON
- Git
- Terminal Linux

## Instal·lació

Clona el repositori:

```bash
git clone URL_DEL_REPOSITORI
```

Entra a la carpeta:

```bash
cd agenda_persistent
```

Executa:

```bash
python agenda_persistent.py
```
